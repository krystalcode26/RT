1. What is HTML and what is its main responsibility in a web page?
HTML (HyperText Markup Language) structures content on a web page — it defines what's a heading, paragraph, image, link, etc. It's not for styling or behavior, just structure and meaning.

2. What is an HTML file essentially made of?
An HTML file is made of elements, each written as a tag (or pair of tags) that wraps content, like <p>text</p>. The whole file is a nested hierarchy of these elements.

3. What does <!DOCTYPE html> do and why is it required?
It tells the browser to render the page in standards mode (modern HTML5 rules) instead of quirks mode, which mimics old, inconsistent browser behavior. Without it, browsers can render CSS and layout unpredictably.

4. What is an HTML tag and how does it work?
A tag is a keyword wrapped in angle brackets that marks the start (<p>) and end (</p>) of an element. The browser reads the tag name to know how to treat the content inside — some tags are self-closing (<img>, <br>) since they don't wrap content.

5. What is the difference between the <head> and <body> sections?
<head> holds metadata not shown directly on the page — title, character encoding, linked CSS/JS files, SEO tags. <body> holds everything the user actually sees and interacts with — text, images, buttons, etc.

6. What is an HTML attribute and why is it needed?
An attribute adds extra information to a tag, written as name="value" inside the opening tag, e.g. <img src="cat.jpg" alt="A cat">. It's needed because some elements require configuration the tag name alone can't express — a link needs a URL, an image needs a source.

7. How does the browser parse HTML and convert it into the DOM?
The browser reads the HTML top to bottom, tokenizes it into tags and text, and builds a tree of nodes representing the nesting — this is the DOM. Each tag becomes a node whose parent is whatever element contains it.
CSS

8. What is CSS and what problem does it solve?
CSS (Cascading Style Sheets) controls the visual presentation of HTML — colors, fonts, spacing, layout — separating design from structure so the same HTML can look different with different CSS.

9. Why is CSS not considered a programming language?
CSS has no logic constructs like loops, conditionals, or variables in the traditional programming sense (custom properties aside) — it's a declarative rule system that describes what something should look like, not a sequence of instructions to execute.

10. What are the three ways to apply CSS to an HTML page?
Inline (a style attribute on the element), internal (a <style> block in the <head>), and external (a separate .css file linked via <link>).

11. Why are inline styles generally not recommended?
They mix presentation into markup, making styles hard to reuse, override, or maintain across many elements, and they have very high specificity, which can make debugging CSS conflicts frustrating.

12. What is the difference between id selectors and class selectors in CSS?
An id selector (#header) targets exactly one unique element and has higher specificity; a class selector (.card) can be applied to many elements and is meant for reusable styling.

13. What is the difference between margin and padding?
Padding is the space inside an element, between its content and its border. Margin is the space outside the element, between its border and neighboring elements.

14. What is the difference between position: relative and position: absolute?
relative positions an element relative to its normal position in the flow (offsets shift it but leave a "gap" where it would've been). absolute removes it from normal flow entirely and positions it relative to its nearest positioned ancestor (or the page if none exists).

15. What is JavaScript used for in a web application?
It adds interactivity and dynamic behavior to a page — responding to clicks, updating content without a reload, validating forms, fetching data, animating elements, and so on.

16. What are the two ways to include JavaScript in an HTML file?
Inline in a <script> tag directly in the HTML file, or externally by linking a .js file with <script src="file.js"></script>.

17. What is a variable in JavaScript and what types of values can it store?
A variable (declared with let, const, or var) is a named container for a value. It can hold numbers, strings, booleans, objects, arrays, functions, or null/undefined — JavaScript is dynamically typed, so the same variable can even hold different types over time (with let/var).

18. How does JavaScript interact with HTML elements through the DOM?
JavaScript uses the DOM API to read and modify HTML elements — methods like document.querySelector() find elements, and properties like .textContent, .style, or .classList let JS change what's displayed, essentially treating the page as a tree it can inspect and edit live.

19. What are loops used for in JavaScript, and can you give an example use case?
Loops (for, while) repeat a block of code multiple times. A common use case: looping over an array of items fetched from an API and creating a DOM element for each one, like rendering a list of products on a page.

20. What is an event listener and why is it important in front-end development?
An event listener is a function attached to an element that runs in response to a specific action — a click, a keypress, a form submission. It's central to front-end dev because it's how static pages become interactive, letting code react to what the user does rather than running once and stopping.
